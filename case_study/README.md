# Testing Assessment Case Study

This directory preserves a concrete beta assessment and production-readiness
decision from a separate Python project. It demonstrates how the repository's
L1, L2, and L3 procedures can retain observed values, inference, limitations,
blocking evidence, and project-specific thresholds.

The assessed project's source, tests, baselines, and command harness are not
part of this repository. The commands and measurements are therefore historical
case-study evidence, not reproducible claims about `../example_project/` and not
defaults for another project.

Use:

- `current-assessment.md` for a beta/stabilization decision;
- `production-readiness.md` for the stricter production-release decision.

The case study intentionally preserves some repeated product context because the
two documents support different decisions. Stable definitions and general
requirements remain canonical in `../glossary.md`, `../Overview.md`, and the
applicable L1/L2/L3 procedures.
